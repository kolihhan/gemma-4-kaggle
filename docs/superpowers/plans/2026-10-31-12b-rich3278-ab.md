# 12B `rich_3278` A/B Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run the current coder + verifier AgentTool candidate on `rich_3278` with Gemma 4 12B as the only experimental variable.

**Architecture:** Keep the canonical topology, prompts, sampling, and budgets unchanged on an isolated experiment branch. Change both declared agent models to 12B, adapt the smoke runtime to the official 12B vLLM override, and run a dedicated private Kaggle L4 smoke workflow.

**Tech Stack:** GitHub Actions, Kaggle CLI, Kaggle L4 x4, Python 3.12, `adk-submission`, `swegemma`, vLLM.

**Spec:** `docs/design/12b-rich3278-controlled-ab.md`

## Global Constraints

- Only base model may change: E4B -> 12B.
- Use Kaggle Staff's `--hf-overrides` for 12B.
- Do not change prompts, topology, tool ownership, sampling, task, or evaluation budget.
- Do not merge experiment state into `main` before evidence is reviewed.

## Review Focus

- Root and verifier accidentally use different model variants.
- 12B runtime starts without the required HF override.
- Workflow attaches the wrong Kaggle model resource/version.
- Smoke result assertion still expects E4B and masks a bad run.
- Prompt or budget drift contaminates the A/B.
