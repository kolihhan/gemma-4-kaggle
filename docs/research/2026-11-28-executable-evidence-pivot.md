## Attack the DEC premise
[Moving Failures Around draft F4–F6](https://github.com/lspecian/gemma4-moving-failures/blob/main/paper/draft.md) reports that strong-model exploration rarely read files Gemma had not read; average pre-first-edit experiments were 4.4 vs 1.7, and strong exploration took 23–34 median calls before the first edit vs Gemma's 28-call budget. Tool-output handoff on selected 23 hard tasks achieved 35% attempt success vs 3.4% at real-budget Gemma; 30m Gemma 17%, handoff with reasoning 44%. Selected cohort, unequal conditions, author-reported. Crucial negative: automatically delivered repository tests (64% of findable tasks included a file modified by hidden tests) gave 46 vs 45 and 35 vs 34 local solves, no persuasive effect. Suggested experiment tool was called in 0/10 opportunities when expected behavior required model input; narrow no-input variant used on two tasks, one misread input, only 1/23 solved. External model-assisted labels for 134 wrong patches estimate 49% unstated requirements; do not equate to our distribution.

Decision: DOWNRANK DEC static AST/caller evidence as primary improvement mechanism. Handoff is evidence for **behavior-discriminating observations**, not proof more source snippets help. Do not expand static retrieval prototype, generic verifier, mandatory prompt or test tool unless new evidence identifies a necessary fact and delivery mechanism. Preserve original spec as conditional prior hypothesis. No score claim.
