## 3. Attack the premise
Premise repeatedly shared: giving the same model more/less time or another procedural instruction will reliably turn failures into correct patches. Predicted observable: intervention uptake and higher eligible paired correctness beyond A/A. Observed: FORK checkpoint uptake zero, unchanged correctness; C changes process and +1 on reused six, not independently verified; external Think-1024 zero net. Premise **not supported** as dominant cause. Do not implement another unconditional workflow.

| Hypothesis | Evidence for / against | Falsifier / observation |
|---|---|---|
| H1 requirements misunderstood | stable failures rarely show explicit reproductions; short external URL historical examples; no blinded semantic labels | reviewer independently derives requirement, trace correctly states it before edit |
| H2 missing useful information | multifile skew, incomplete all-file requests, external handoff study; relevant file requests frequent | adequate necessary caller/branch/test output visible before edit, but wrong implementation persists |
| H3 causal inference incorrect | possible when wrong branch chosen despite adequate evidence; no reliable chronology labels | trace correctly predicts causal path and counterfactual before edit |
| H4 edit/code failure | nonempty wrong patches frequent; malformed edit grammar associated with two regressions | exact diff implements correct intended behaviors, valid application; remaining failure environment or hidden requirement |
| H5 weak behavioral witness | public agents sometimes pass self-test then grader fail; owner witness replay blocked | genuine existing witness discriminates correct/incorrect patches with adequate coverage and model uses feedback |
| H6 wrong candidate selection | oracle union 12/17 vs Champion 10; four arms include different policies, not pass@4 | no correct alternative generated or no observable test can choose it |
| H7 budget/serving | fatal thought and timeout correlations, 8m official timeout; no >=55 calls in FORK; budget treatment weak | task terminates with complete evidence and valid wrong diff under budget |
| H8 evaluation mismatch | 0/35 fresh gold/noop eligible, earlier gold failure; prior 17 valid | reproduce exact clean current controls and log separate failure stages |
| H9 policy/model capability | 31B beats 12B by one task on tiny four; teacher handoff helps but still leaves failures | same 31B with sufficient evidence consistently repairs hard cases, then focus on evidence acquisition |

Rank H8 as experimental blocker, H2/H3/H4 as candidate explanatory cluster, H5/H6 conditional; no causal prevalence claim. Directly test information adequacy before adding architecture. Four observed outcomes permit oracle improvement at most 2/17 over current control, whereas 0.18->0.25 is +7 percentage points (~39% relative) and local/hidden mapping is unknown. Do not extrapolate.
